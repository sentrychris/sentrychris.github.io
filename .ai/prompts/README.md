# Prompts

Reusable, project-specific prompts for AI agents. Currently empty.

Add one when you find yourself giving the same brief to an agent
twice — for example: scaffolding a new Vigil component from its
`BRANDING.md` recipe, drafting a project case study from raw notes,
or reviewing a section against the design language.

Each prompt should be a standalone Markdown file, named for what it
produces (e.g. `new-component.md`, `case-study-from-notes.md`).
