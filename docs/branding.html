IdentityNº I

Printed editorial, set in serif italic, at day or night.

Atlas reads like a small magazine. Plain declarative copy in a warm sans, italic Playfair only for accent phrases and numerals, mono caps for labels. A green accent acts like an LED — present everywhere, dominant nowhere.

Three sensibilities

Editorial. Serif italic accents, generous whitespace, manuscript rhythm.

Manifest. Plain declarative copy, numbered sections (Nº 01), coordinates as marginalia.

Quiet craft. Soft drop shadows, hairline ink highlights, no neon, no glass, no frame chrome.

Six things that cannot be dropped

  1. The paper-and-ink palette (cream/forest, light or dark).
  2. The type triumvirate — Montserrat, Playfair italic, JetBrains Mono.
  3. The accent leading-dash on every section eyebrow.
  4. The italic Playfair accent phrase on hero/section titles.
  5. The Nº NN badge on each section.
  6. Restrained motion under prefers-reduced-motion.
ColourNº II

Two themes, one palette.

Light is the default — warm parchment cream, deep forest ink, deeper emerald accent. Dark inverts to forest paper and pale mint ink. Both share the same green accent family. The runtime flips between them via data-theme on <html>.

These two panels are forced light and dark for side-by-side comparison — they don't follow the page theme. Toggle the rest of the page via the ☀ / ☾ button at the top-right.

LayoutsNº VI

Five panels, five recipes.

Sections alternate between two registers: Vogue (centred editorial composition with italic accents and fleurons) and Diagram (architectural drawing spread with title blocks, plates, schedules). The order is About (Vogue) → Skills (Diagram) → Experience (Vogue) → Projects (Diagram) → Contact (Vogue).

Desktop horizontal pager

On desktop (≥921px) <main> becomes a horizontal scroll container with scroll-snap-type: x mandatory; each section is a 100vw × 100vh panel. The useHorizontalScroll hook converts vertical wheel events (when a section's internal scroll is exhausted) into smooth main.scrollTo calls between panels. Mobile keeps the natural vertical long-scroll.

Vertical centring

Every panel uses display: flex; flex-direction: column; justify-content: safe center. With symmetric top/bottom padding, content sits at the actual viewport midpoint. Long panels (e.g. Projects) keep overflow-y: auto as a fallback so the wheel hijack can pass through.

Tracker offset

Section padding-left is clamp(180px, 14vw, 280px) so the fixed Tracker (~175px wide on the left edge) never overlaps content. Content centres within the remaining width.

MotionNº VII

Subtle by default, respectful always.

Atlas runs no entry transitions and no global hover eases — all CSS transitions are killed at the root. Motion is reserved for ambient indicators (the contact pulse), the horizontal-pager animation, the schematic parallax, and a handful of one-shot moments (Hero count-up, Tracker ping). Everything bows to prefers-reduced-motion.

Pulse dot — Contact status

Open to work · Replies within a day

8px accent dot, 1.6s ease-in-out opacity 1 → 0.35 → 1. CSS animation, gated under reduced-motion.

Tracker sonar pulse

Active dot emits two staggered hairline accent rings (::before + ::after) that scale from 1 → 3.4 with opacity 0.7 → 0 over 2.2s, 1.1s offset. Reads as a soft radar ping.

Tracker ping travel

On activeId change, a small accent dot animates along the rule from the previous entry to the new one via Web Animations API — bypasses the global transition: none rule.

Schematic parallax

As main.scrollLeft changes, the grid (background-position) drifts at 15%, the SVG shapes (transform) drift at 5%, the corner ornaments stay anchored. Three depth layers, framerate-friendly via requestAnimationFrame throttling. Live demo below ↓

Hero number count-up

The useCountUp hook ticks a number from 0 to its target via requestAnimationFrame with an ease-out cubic over 1.2s on first mount. Respects reduced-motion (returns the final value immediately).

Cursor-tracked spotlight + tilt

Project images carry an accent-tinted overlay with a radial-gradient mask cut by --mx / --my on mousemove. Hero project also tilts via perspective(1400px) rotateX/Y.

SpacingNº VIII

A 4rem rhythm, top to bottom.

Section padding cascades 7→5→4→3rem from desktop to small phone. Opener bottom margin cascades 4→3→2.4→2rem. Inter-block gaps (rosters, fleurons, signatures) align to the 4rem baseline so the whole long-scroll feels like one rhythm.

VoiceNº IX

Plain, declarative, operator-tone.

Atlas reads like a cover letter from someone who's tired of marketing-speak. Specific verbs, concrete numbers, no hedging, no pomp. The italic accent phrases carry the only touch of romance.

— Do

Lead with verbs. "Inheriting complex legacy systems, shipping clean code."

Specific numbers. "12+ years", not "a decade".

Sentence case for everything. Title Case is for film posters.

One italic accent per heading.

Plain English alternatives to jargon when both work.

— Don't

Don't hype. "Game-changing", "world-class", "cutting-edge" are out.

Don't pluralise. The site is one page, not "pages".

Don't ALL CAPS sentences. Caps are for mono labels only.

Don't pad with adjectives. "Beautiful web apps" is the maximum.

Don't sign off with emoji. The fleuron and italic Playfair carry that role.
